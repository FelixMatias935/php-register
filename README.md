**Sistema de Cadastro – PHP + MySQL**

Este é um mini sistema de cadastro desenvolvido como projeto de estudo e portfólio.  
Ele demonstra de forma simples e segura como funciona o processo de:

- Receber dados de um formulário
- Validar informações
- Criar hash seguro de senha
- Usar Prepared Statements (anti SQL Injection)
- Salvar dados em um banco MySQL
- Exibir mensagens usando PRG (Post-Redirect-Get)

🚀 Tecnologias Usadas
- **PHP** (mysqli + prepared statements + password_hash)
- **MySQL** (utf8mb4)
- **HTML5**
- **CSS3**
- **JavaScript** (mostrar/ocultar senha)

🧠 Funcionalidades
- Cadastro com username e senha
- Validação de senha forte (regex)
- Proteção contra SQL Injection
- Mensagens dinâmicas (erro/sucesso)
- Sistema de flash messages via sessão
- Interface simples e funcional
